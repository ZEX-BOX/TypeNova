# Public Reference Research — TypeNova

Research date: 4 November 2026. Method: public pages and indexed product documentation. No login, paywall, bot protection or access-control bypass was attempted. This is a first-pass desk review, not a complete interactive audit.

## YouType — youtype.tech

Verified public observations:
- Public homepage presents a typing trainer and keyboard practice.
- Public lessons page shows a structured Touch Typing Fundamentals curriculum; the crawled view showed 175 lessons and an opening lesson focused on the F key.
- Public simulator page lists support chat, email, programming and application/document workflows, plus keyboard/language layout options.
- Public about content describes speed tests with certificates, games, error analysis, keyboard testing, school/class workflows and company training.
- Simulator content also lists a piano-like interaction and movement break; these are adjacent engagement features.

TypeNova implications:
- Structured lessons and a keyboard/finger guide.
- Real-world writing simulations separate from raw speed tests.
- Educator/team features later, not a launch blocker.
- Certificates and games require validation and anti-cheat design.

Sources:
- https://youtype.tech/
- https://youtype.tech/en/lessons
- https://youtype.tech/en/simulator
- https://youtype.tech/about

## YouType — youtype.app

Verified public observations:
- The public product is an audio-first English learning experience: listen, understand and type.
- Public content presents courses and chapters, with a flow to find a course, choose a chapter and resume later.
- Practice combines audio, typing, progressive Easy/Medium/Hard difficulty and hints.
- The site describes mistake collection for focused retry in the original sentence, scheduled review, saved vocabulary, personal notes, study-time history, check-ins and rankings.
- Account-dependent course progress and notebooks are described. The page distinguishes free account features from membership features; commercial terms may change.
- The public courses page describes early access; availability is time-sensitive.

TypeNova implications:
- Audio-first language typing with replay speed controls.
- Retry mistakes in original sentence context.
- Optional vocabulary and notes with review scheduling.
- Explicit guest/demo vs signed-in progress boundaries.

Sources:
- https://youtype.app/
- https://youtype.app/courses

## TypeQuicker

Verified public observations:
- Public homepage describes touch-typing courses, targeted practice, weak-character analysis, hand/finger progress and activity history.
- Public feature pages describe daily tests, snippets, custom text, SmartPractice, TypeAnything, TargetPractice, code modes, themes, bigram/trigram analysis, character/word analysis, speed distribution and AI insights.
- Public SmartPractice documentation describes monitoring speed, accuracy and hesitation; identifying weak characters/sequences/words; generating custom text; and adapting difficulty.
- Public code mode documentation lists multi-language programming practice, snippets and custom code.
- Public homepage describes replay and numpad practice.

TypeNova implications:
- Weakness detection uses measured samples and confidence thresholds.
- Start adaptive practice with deterministic rules; AI-generated text can be optional later.
- Code practice must preserve syntax, whitespace, punctuation and indentation.
- Replay and per-key/n-gram analytics need transparent metric definitions.

## Cross-product synthesis
- Structured curriculum: YouType.tech and TypeQuicker; TypeNova core.
- Audio and contextual language learning: YouType.app; TypeNova core module.
- Real-world simulations: YouType.tech and TypeQuicker custom/code modes; TypeNova core module.
- Weak-key adaptive drills: YouType.tech error analysis and TypeQuicker SmartPractice; TypeNova differentiator.
- Games, certificates and rankings: YouType.tech and TypeQuicker public pages; TypeNova later phases.
- Desktop/offline: not verified for these references in this first pass; TypeNova-specific differentiator.
