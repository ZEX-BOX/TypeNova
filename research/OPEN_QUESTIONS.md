# TypeNova Open Product and Engineering Questions

These decisions remain open until research and user review. Do not silently invent answers.

## Product and audience
- Primary launch audience: beginner learners, students, office users, programmers, language learners or balanced?
- Initial UI languages: English only or English + Urdu?
- Keyboard layouts: US QWERTY first or multiple layouts at launch?
- Multilingual typing courses or English-first?

## Scoring and testing
- Which net-speed error penalty should be used?
- Should backspace-corrected errors affect final accuracy, gross speed, both or neither?
- First-class test durations: 15s, 30s, 60s, 3m, 5m?
- Disable paste for tests? How should IME/composition work?
- Minimum sample count before per-key and n-gram recommendations?

## Content and rights
- Who authors original lessons, passages, audio and code examples?
- Which open-license content is acceptable, and how is attribution recorded?
- Human recordings, licensed TTS or browser speech synthesis?
- Moderation requirements for user snippets and custom text?

## Accounts, privacy and monetization
- Required identity providers?
- Guest-to-account progress migration behavior?
- Session event retention and user export/deletion requirements?
- Free tier vs paid membership? No pricing assumptions are committed.
- Global, friends-only, school/team or opt-in anonymous leaderboards?

## Desktop and operations
- Minimum supported Windows version and architecture?
- macOS/Linux in first public release or later?
- Offline content download and storage limits?
- Desktop signing/updater and distribution approach?
- Hosting region, backup policy and operating budget?

## Research validation
- Which public workflows should REA inspect first?
- Which flows are accessible without sign-in?
- Which observations need screenshots/device testing?
- Acceptance criteria for each P0 feature?
