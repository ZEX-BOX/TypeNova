## TypeNova differentiation
1. One consistent typing engine shared by browser and desktop.
2. Local-first desktop practice with durable, transparent cloud synchronization.
3. One progress model across touch typing, language/audio, code and real-world simulations.
4. Transparent metrics with definitions, sample sizes and confidence thresholds.
5. Privacy-first capture only within active TypeNova practice surfaces.

P0 = required for a credible initial product. P1 = high-value complete-platform features. P2 = expansion after core quality. Priorities are TypeNova recommendations, not ratings of reference products.
